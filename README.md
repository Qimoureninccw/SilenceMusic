# Silence Music

一个基于网易云音乐 API 的纯前端音乐播放器。

## 技术栈

- **语言**：TypeScript、React 18
- **构建**：Vite
- **样式**：Tailwind CSS v4
- **状态管理**：Zustand
- **路由**：React Router v6
- **图标**：Lucide React

## API

- **音乐元数据**：SilenceMusicAPI（`https://silence-music-api.de5.net`，网易云 API Enhanced）
- **音频地址**：Meting API（`https://api.qijieya.cn/meting/`）

## 说明

本项目仅供学习交流使用。
